# PatagoniaSoft SRL
## Módulo Integrado de Gestión de Clientes y Proyectos
Trabajo Práctico Integrador de Organización Empresarial. Tecnicatura Universitaria en Programación a Distancia, Universidad Tecnológica Nacional.

**Autora:** Mariana de Mendonça. **Modalidad:** individual. **Caso:** empresa ficticia de Comodoro Rivadavia.

## Problema y propósito
La información de clientes, requerimientos y avances está dispersa en planillas, correos y documentos. Se propone centralizarla para mejorar la coordinación entre Comercial, Desarrollo, Administración y Gerencia.

## Alcance de la primera versión
Registrar clientes, proyectos, requerimientos y tareas; asignar responsables; actualizar estados; controlar fechas y consultar un tablero. Facturación, aplicación móvil, IA e integraciones se reservan para versiones posteriores.

Este repositorio documenta el diseño del sistema. No contiene una aplicación implementada ni certifica resultados de pruebas de rendimiento.

## Gestión del trabajo
Se utilizarán Issues y GitHub Projects con los estados Por Hacer, En Progreso y Listo. El tablero y las referencias a las evidencias se agregarán cuando existan. El desarrollo previsto dura ocho semanas; ese cronograma del sistema es distinto del plazo académico de esta entrega.

El trabajo se realiza individualmente. La modalidad de revisión de pares del Pull Request se encuentra pendiente de indicación del tutor. No se declara realizada esa revisión.

## Declaración de Uso de IA
Utilicé ChatGPT en el rol de compañero de cursada, para proponer historias de usuario, criterios de aceptación, documentación y representación del proceso. Los prompts partieron de las consignas y las entregas anteriores, solicitando mantener el alcance de PatagoniaSoft y distinguir acciones humanas de tareas automáticas. La responsabilidad del contenido presentado corresponde a la autora. Ver [registro y revisión](docs/uso_ia.md).
